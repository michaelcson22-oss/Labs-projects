# Microsoft 365 Administration Lab

## Overview

This project documents my hands-on experience administering Microsoft 365 services through Microsoft 365 Admin Center and Microsoft Entra ID. The lab focuses on common administrative tasks performed by IT Support Technicians and Microsoft 365 Administrators, including identity management, licensing, user administration, authentication, device management, and security.

The objective of this lab is to develop practical experience managing cloud-based Microsoft environments while reinforcing concepts learned through professional experience, personal labs, and Microsoft certification studies.

---

# Objectives

- Manage Microsoft 365 users
- Configure Microsoft Entra ID
- Assign Microsoft licenses
- Manage authentication methods
- Configure security settings
- Perform common IT administration tasks
- Document Microsoft cloud administration procedures
