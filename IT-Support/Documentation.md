# IT Support Documentation

## Overview

This repository documents the real-world IT support tasks and procedures I have performed while working as a Tier 1 IT Support Technician. It serves as a knowledge base of common help desk responsibilities, troubleshooting techniques, user administration tasks, endpoint management, and Microsoft 365 administration. Documentation is the biggest part being in IT Support

The goal of this repository is to document best practices, improve troubleshooting efficiency, and demonstrate hands-on experience supporting end users in a business environment.
